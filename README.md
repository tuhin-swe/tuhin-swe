## About Me

SQA Engineer from Dhaka, Bangladesh, with a B.Sc. in Software Engineering (Daffodil International University, CGPA 3.60/4.00). I test live SaaS products across **e-commerce, food delivery, ride-sharing and point-of-sale** domains, covering the website, admin panel and mobile apps (customer, rider/driver and seller/restaurant).

I focus on clear bug reports with root-cause analysis, reproduction steps and severity/priority, plus REST API testing with Postman. I'm now building test automation skills through the **Full Stack SDET: Road to SDET** program.

## Experience

**Junior SQA Engineer, RazinSoft** (Aug 2026 – Present)
- Manual testing of multiple SaaS products on web, admin panel and mobile apps
- REST API testing with Postman: response codes, JSON payloads, and business logic such as fee and commission calculations
- Writing bug reports with root-cause analysis and severity (Critical/Major/Minor/Low) and priority classification
- Retesting fixes across releases and reviewing admin/seller workflows to catch functional gaps before production

**SQA Intern, Goinnovior Limited** (Nov 2025 – Jan 2026)
- Manual and functional testing on live projects under senior QA guidance

**Support Team Lead, Shohoz Software** (Sep 2024 – Sep 2025)

- Progressed from Software Support Executive to Interim Team Lead to Support Team Lead
